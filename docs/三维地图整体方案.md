## 1. 一句话

用工位头上的 **RealSense D435** 扫一圈，用 **nvblox** 融出彩色点云；再在 **Foxglove** 里叠上 **URDF 双臂**，按录好的关节轨迹播放。用来给人看「场景长什么样、臂和地图对不对齐」，**不拿来做避障证明**。

---

## 2. 点云怎么出的

```text
头 D435（彩色 + 深度/FFS）
    + 手眼标定 T_base_cam（首帧锚定）
    + 后续位姿：cuVSLAM（头红外双目）
        ↓
nvblox 只融合头路（HEAD_ONLY，不融腕 D405）
        ↓
live_cloud.ply（彩色点云）
        ↓
打成 MCAP → Foxglove：点云 + URDF + 关节回放
```

常用启动（容器内）：

```bash
HEAD_ONLY=1 KEYFRAMES=1 KEYFRAMES_CAMERAS=head \
  bash /workspaces/nvblox/tools/run_mapper_dual_ffs.sh
```

Foxglove 打包（主机）：

```bash
# 读最终点云 / 网格 + 关节，出 session_*.mcap
./tools/run_record_foxglove_mcap.sh
```

**用了什么：**

| 项 | 做法 |
| --- | --- |
| 相机 | 头 **D435**（演示只用这一路） |
| 深度 | 头路 FFS / 或硬件深度 |
| 位姿 | 首帧手眼 `T_base_cam`，后面 **cuVSLAM** |
| 建图 | **nvblox** TSDF，落盘彩色点云 `live_cloud.ply` |
| 展示 | Foxglove：`/map` 点云 + `/arm` URDF（当前 rimbot-TJ URDF）+ 关节轨迹 |

本地常见产物：`live_cloud.ply`、`gpu_logs/session_head_final.mcap`。

## 3. 效果怎么样

**观感：** 点云比之前试过的「渲染向」结果更适合当前演示；工位桌面、大块结构能看清，和 base 系对齐后臂在图上能动。

**录屏（自己贴）：**

1. 建图过程 / 点云效果  

2. Foxglove：点云 + URDF 臂动画  

**已知局限（口头带一句就行）：**

- 单头覆盖小，很多角落/桌下扫不到。  
- 头相机基本固定或只能转，不如腕相机灵活。  
- 腕 **D405 + FFS** 重复扫桌/墙时点云容易「不共面」，所以**演示主线不用腕点云**；后面补细节还是要腕深。

## 4. 和避障地图的区别

| | 这份演示地图 | 避障用地图 |
| --- | --- | --- |
| 目的 | 给 +1 / 客户看场景 + 臂 | 几何可靠、给规划用 |
| 主资产 | 单 435 彩色点云 + URDF | nvblox TSDF/后续 ESDF 等 |
| 腕相机 | 演示不用 | 后续近距/补盲仍需要 |
