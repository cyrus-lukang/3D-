## 2. 构建 RealSense 例程 Docker（首次，较久）

> 注意：本仓库 CI 参数是 `--build-image`，不是旧文档里的 `--image`。  
> 本机是 Ubuntu 22.04，建议显式指定 `--ubuntu-version 22`。

```bash
cd /home/ubuntu/workspace/lk_ceshi/nvblox_3D重建
python3 ci/nvblox_ci.py --build-image realsense --ubuntu-version 22
```

编完后确认镜像：

```bash
docker images | grep realsense
```

期望镜像名类似（以 `docker images | grep realsense` 为准）：

```text
nvblox_realsense_example_x86_64_cu12_u22
```

## Orbbec Gemini 335L（同一套 nvblox + Rerun）

和 D435 相同：`cuVSLAM（双目 IR）+ nvblox GPU TSDF + Rerun 可旋转点云/体素`。只换相机为 Gemini 335L。

```bash
cd /home/ubuntu/workspace/lk_ceshi/nvblox_3D重建
pkill -f OrbbecViewer 2>/dev/null || true
# 交互进容器（推荐，Rerun 可转视角）
DISPLAY=:1 bash tools/run_orbbec_nvblox_docker.sh
# 容器内：
export PATH=/opt/venv/bin:$PATH
bash /workspaces/nvblox/docker/install_realsense_usb2_patch.sh
export DISPLAY=:1
bash /workspaces/nvblox/tools/run_mapper_orbbec_335l.sh \
  2>&1 | tee /workspaces/nvblox/gpu_logs/mapper_orbbec_live.log
```

一键（非交互）：`DISPLAY=:1 bash tools/run_orbbec_nvblox_docker.sh --run`
